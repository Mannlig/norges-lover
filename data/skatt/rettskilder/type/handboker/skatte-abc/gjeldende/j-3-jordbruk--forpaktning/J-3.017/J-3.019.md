## J-3-4.2 Bortforpakter

Inntekter og kostnader følger realisasjonsprinsippet.

Verditilvekst som er tilført bortleide formuesobjekter for forpakterens regning, er skattepliktig inntekt for bortforpakteren som forskuddsbetalt leie og fordeles til inntekt over restleieperioden. Om aktivering hos bortforpakter, se emnet [Driftsmiddel – allment om fradrag for inngangsverdi](https://www.skatteetaten.no/rettskilder/type/handboker/skatte-abc/gjeldende/d-1-driftsmiddel--allment-om-fradrag-for-inngangsverdi/), [pkt. D-1-6.6](https://www.skatteetaten.no/rettskilder/type/handboker/skatte-abc/gjeldende/d-1-driftsmiddel--allment-om-fradrag-for-inngangsverdi/D-1.040/D-1.046/). Kostnader til større vedlikehold som forpakter tar på seg som en del av forpaktningsavtalen, og som blir inntektsført som tilleggsleie hos bortforpakter, se [pkt. J-3-3.5.2](https://www.skatteetaten.no/rettskilder/type/handboker/skatte-abc/gjeldende/j-3-jordbruk--forpaktning/J-3.005/J-3.014/#j-3-016-j-3-3-5-2-bortforpakter), kan fradragsføres hos bortforpakteren i det året vedlikeholdet utføres.

Se for øvrig emnene om tidfesting av inntekter og kostnader.
