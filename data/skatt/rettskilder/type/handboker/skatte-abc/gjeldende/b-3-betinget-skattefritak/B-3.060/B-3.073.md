## B-3-4.6 Hva regnes som reinvestert beløp

Som reinvestert beløp regnes alle kostnader ved erverv av det nye formuesobjektet og/eller påkostning som nevnt i [pkt. B-3-4.4](https://www.skatteetaten.no/rettskilder/type/handboker/skatte-abc/gjeldende/b-3-betinget-skattefritak/B-3.060/B-3.071/). Om hva som regnes som kostnader ved erverv av nytt formuesobjekt, se emnet [Inngangsverdi](https://www.skatteetaten.no/rettskilder/type/handboker/skatte-abc/gjeldende/i-3-inngangsverdi/).

Reinvestert beløp fastsettes på tilsvarende måte som ved ufrivillig realisasjon, se nærmere [pkt. B-3-2.7](https://www.skatteetaten.no/rettskilder/type/handboker/skatte-abc/gjeldende/b-3-betinget-skattefritak/B-3.002/B-3.027/).
