## B-3-4.8 Hvem som kan reinvestere

I utgangspunktet er det den som var eier av den innløste eiendommen som selv må erverve den nye eiendommen eller eie det objektet som påkostningen foretas på. Hvem som kan reinvestere følger samme regler som ved ufrivillig realisasjon, se nærmere i [pkt. 2.9](https://www.skatteetaten.no/rettskilder/type/handboker/skatte-abc/2024/b-3-betinget-skattefritak/B-3.002/B-3.035/).
