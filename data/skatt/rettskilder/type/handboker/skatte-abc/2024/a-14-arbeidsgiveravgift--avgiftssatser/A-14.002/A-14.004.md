### A-14-2.2.2 Satsene i de ulike sonene

Avgiftssatsene i de ulike sonene er:

| Sone | Ordinære næringer | Landbruk og fiske |
| --- | --- | --- |
| I | 14,1 % | 14,1 % |
| Ia | 10,6 % (14,1 % etter fribeløp*) | 10,6 % |
| II | 10,6 % | 10,6 % |
| III | 6,4 % | 6,4 % |
| IV | 5,1 % | 5,1 % |
| IVa | 7,9 % | 5,1 % |
| V | 0 % | 0 % |

* Satsen på 14,1 % skal benyttes etter at et fribeløp på kr 850 000 er brukt opp.
